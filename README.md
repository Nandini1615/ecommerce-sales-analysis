# 🛒 E-Commerce Sales Analysis using Python

### 📊 Project Overview
Analyzed e-commerce sales data to uncover business insights like top-selling products and highest-performing cities. Built as a fresher Data Analyst portfolio project.

### 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib

### 🔍 Key Analysis
- Calculated Total Sales
- Sales by Product (groupby)
- Sales by City (groupby)
- Found Top Product and Top City
